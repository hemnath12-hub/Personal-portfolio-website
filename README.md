# Personal Portfolio Website 🌐

A responsive and modern personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my skills, projects, and professional background as a web developer.

## 🚀 Features
- Attractive and responsive design
- Home section with introduction and skills summary
- About Me section with education and experience
- Skills showcase using card layout
- Projects section to highlight work
- Clean and user-friendly UI

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Basic interactivity

## 📂 Project Structure
├── index.html
├── style.css
└── script.js


## 🎯 Purpose
This portfolio website acts as a digital resume to present my technical skills and projects in a professional manner. It also demonstrates my understanding of front-end web development and UI design principles.
